# FC RETRO 27

A 1999-style pixel football game with a modern Ultimate Team: packs, market, SBCs, leagues, online matches and FC 27 style tactics.

Play it: https://oily-spatial-networks--CJO00.replit.app/ (Replit) or https://joel-studio.github.io/FC-retro-27/ (GitHub Pages, once Pages is switched on)

Plain HTML, CSS and JavaScript, no build step: open `index.html` or serve the folder as static files.
